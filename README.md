# CLIMB UP

How high you climb isn't how you win.

A mobile mountaineering strategy and adventure game. The first expedition is a simplified ten-day Kilimanjaro (Lemosho): camp decisions each day and night, and, at the Barranco Wall, a short playable climb whose outcome feeds back into the expedition. Reaching the summit is not the win. A careful retreat can outscore a reckless summit, and a summit without a safe return is not a successful expedition.

This is a simplified game about expedition judgment. It is not professional mountaineering instruction, a route description, or medical advice.

```bash
npm start
```

Open the project in Expo Go, or run `npm run web` for the browser build.

```bash
npm test
npm run typecheck
npm run lint
```
