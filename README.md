# CLIMB UP

How high you climb isn't how you win.

A mobile mountaineering strategy and decision game. The playable expedition is a fictional ten-day Kilimanjaro journey. The Barranco Wall morning is a short scramble you walk. Reaching a summit is not the win. A careful retreat can outscore a reckless summit, and a summit without a safe return is not a successful expedition.

Notes on the hybrid loop, the picture, and how to test it are in `docs/`.

This is a simplified game about expedition judgment. It is not professional mountaineering instruction, a route description, or medical advice.

```bash
npm start
```

Open the project in Expo Go, or press `w` for the web build.

```bash
npm test
npm run typecheck
npm run lint
```
