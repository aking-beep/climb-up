# Asset manifest

Every image in the repository, what uses it, and its state. **License status
"Unrecorded"** means the repository has no record of where the file came from
or under what terms. That must be resolved before any public release.
Commit history shows the `world/` files arriving with the HD-2D diorama and
Kilimanjaro commits, but not their source.

Status key: **Used**: shipped in a reachable screen. **Unused**: in the repo,
not reachable. **Generated**: original art made by a script in `tools/art/`;
re-run the script to change it. **Placeholder**: stand-in art, to be replaced.
