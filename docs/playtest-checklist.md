# Phone playtest: one page

Goal: play the three Kilimanjaro climbs with touch only on a real phone (the
Pixel), and write down what feels bad. One sitting, about 40 minutes.

## Before you start

- [ ] Install the APK: open it on the phone, allow "Install unknown apps" for
      the app you opened it from, install. (It is a debug build.)
- [ ] Battery at ___ % · phone model ________ · Android version ____
- [ ] Phone in landscape, brightness at your normal level, sound on.
- [ ] New expedition, the long way. In any climb, pause (II) and turn
      **Show FPS: On**. Leave it on for the whole test.

## Each climb (Lava Tower, Barranco Wall, Summit night)

Play to the top with your thumbs only. Write a number or a word next to
each line.

| | Lava Tower | Barranco Wall | Summit night |
| --- | --- | --- | --- |
| FPS while walking (lowest you see) | | | |
| FPS in the busiest moment (stones, ravens, wind) | | | |
| Minutes to the top | | | |
| Slips (and whether each felt fair) | | | |
| Times a hop didn't happen when you pressed JUMP | | | |
| Times you walked into something you didn't see coming | | | |
| Could you read the HUD text without squinting? (y/n) | | | |
| Did your thumbs cover anything important? (what) | | | |

## Controls

- [ ] Stick: does walking start and stop where your thumb says? Any drift?
- [ ] JUMP: does a hop come the moment you tap? Over thistles and ants too?
- [ ] CLIMB / pushing up on rock: does it grab when you expect?
- [ ] BRACE in a gust: is it easy to hold while you watch the wind line?
- [ ] REST: easy to find when the bar is low?
- [ ] ACT (talk, read, help): does it say the right word at the right time?

## Readability

- [ ] Can you tell at a glance: stamina low, rocks coming, slab cracking,
      raven calling, ants ahead?
- [ ] Is the brief before each climb readable on the phone, and does
      "Stamina bar N: ..." make sense?
- [ ] At camp: do the choices' "[hours · costs · risk]" lines help you
      decide? Too long to read?

## Feel

- [ ] One thing that felt great: ______________________________________
- [ ] One thing that felt unfair: _____________________________________
- [ ] One moment you were confused about what to do: __________________
- [ ] Did the obstacle tempo feel exciting, or tiring, by the summit night?

## After

- [ ] Battery now ___ %, after ___ minutes. Phone warm / hot / normal?
- [ ] Any crash or freeze? What were you doing?
- [ ] Screenshots of anything odd (power + volume down).

Send the filled page back (a photo is fine) and the next round of fixes
comes from it.
